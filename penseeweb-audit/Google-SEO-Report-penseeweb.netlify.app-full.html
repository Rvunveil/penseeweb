1. Executive Summary

This report presents a comprehensive SEO audit of penseeweb.netlify.app for a SaaS / AI EdTech site, generated on October 22, 2026. Findings combine technical, content, schema, performance, visual, and search-readiness evidence as available.

57/100
SEO Health Score
Critical Issues Found:
  1. Zero Schema.org JSON-LD structured data across all 10 pages, missing SoftwareApplication and Article rich results.
  2. Missing robots.txt and sitemap.xml, leaving search and AI crawlers without discovery or indexing boundaries.
  3. Missing canonical tags on all pages, risking link equity fragmentation across deployment mirrors.
  4. All 5 resource articles share the unoptimized title 'PenseeWeb Studio' and have null meta descriptions.
  5. OpenGraph and Twitter preview images use relative paths and AVIF format, breaking link cards on WhatsApp and Twitter.
Quick Wins:
  1. Deploy custom robots.txt with dedicated AI crawler directives and sitemap declaration.
  2. Generate valid sitemap.xml with accurate W3C timestamps for all 10 pages.
  3. Inject rich JSON-LD (Organization, WebSite, SoftwareApplication with INR pricing, and Article schemas).
  4. Inject self-referencing canonical links and optimized title/description tags on every page.
  5. Deploy llms.txt and llms-full.txt for instant ChatGPT Search and Perplexity citation.

2. Audit Categories

2.1 Technical SEO

Score: 48/100

What Works

  • Fully server-rendered static HTML ensures 100% crawl accessibility without JS execution requirements.
  • Clean, semantic modern layout using Webflow framework components.

Findings

Missing robots.txt Critical

Root robots.txt returns 404, omitting crawler instructions and sitemap discovery.

Recommendation: Deploy robots.txt specifying Googlebot, Bingbot, AI crawler access, and sitemap URL.

Missing sitemap.xml Critical

No XML sitemap is present to guide indexing priority and content modification times.

Recommendation: Generate W3C-compliant sitemap.xml listing all 10 core pages and articles.

Missing Canonical Tags Critical

Zero pages define <link rel='canonical'>, risking duplicate content across Netlify and GitHub Pages.

Recommendation: Add self-referencing canonical tags to all 10 HTML documents.

Multiple H1 Tags Per Document High

Bottom CTA banners are coded as <h1> tags, diluting primary topical relevance.

Recommendation: Demote secondary CTA headings to <h2>.

2.2 Content Quality & On-Page SEO

Score: 68/100

What Works

  • Highly engaging copy tailored to Indian competitive exam culture (Kota, JEE, NEET, UPSC, CA).
  • Clear pricing transparency (₹9 pay-per-map to ₹350/month Pro tier).

Findings

Blank / Generic Metadata on Resource Articles Critical

All 5 resource articles have title 'PenseeWeb Studio' and null meta descriptions.

Recommendation: Inject unique 50-60 character titles and 140-160 character meta descriptions.

Meta Description Truncation on Core Pages High

Homepage, About, and Product descriptions exceed 240-310 characters and get truncated.

Recommendation: Condense meta descriptions to under 160 characters with clear call-to-action.

Leaked Text in Resources Hub Description High

resources.html meta description contains 'Open Graph Settings' export artifact.

Recommendation: Remove leaked string and provide focused snippet text.

Internal '[ARCHIVE]' Marker in Careers H1 Medium

careers.html H1 heading displays '[ARCHIVE] Join the Mindmap Rebellion'.

Recommendation: Remove '[ARCHIVE]' tag from public-facing heading.

2.3 Schema / Structured Data

Score: 0/100

Findings

Total Absence of Schema.org JSON-LD Critical

0 out of 10 pages have structured data, preventing Google Rich Snippets.

Recommendation: Deploy Organization, WebSite, SoftwareApplication, and Article JSON-LD.

2.4 Performance & Core Web Vitals

Score: 78/100

What Works

  • Static page load with low JS execution keeps INP under 120ms.
  • Hero visuals use high-compression AVIF images.

Findings

Synchronous WebFont Loader in Head Medium

webfont.js executes synchronously in <head>, blocking First Contentful Paint.

Recommendation: Ensure font display swap and preload key styles.

Cumulative Layout Shift on Unsized Images Medium

Feature cards lack height dimensions, causing reflow during image load.

Recommendation: Provide explicit dimension or aspect-ratio attributes.

2.5 AI Search Readiness & GEO

Score: 54/100

What Works

  • Unique terminology and strong domain relevance in Indian EdTech space.

Findings

Missing llms.txt and llms-full.txt High

AI models lack a standardized markdown context map for documentation.

Recommendation: Deploy standard llms.txt and llms-full.txt specification files.

Unspecified AI Crawler Policies High

No explicit permission given to ChatGPT Search, Claude Search, or Perplexity bots.

Recommendation: Add allow directives for OAI-SearchBot, Claude-SearchBot, and PerplexityBot in robots.txt.

2.6 Image SEO

Score: 76/100

What Works

  • AVIF adoption across 90%+ of graphic assets.
  • Responsive srcset used on major hero diagrams.

Findings

Incompatible OpenGraph Image Format and Path High

og:image points to relative AVIF file; social crawlers require absolute JPG/PNG.

Recommendation: Update og:image and twitter:image to absolute URLs with JPG/PNG support.

Empty Alt Attributes on Editorial Images Medium

Featured news images have alt=''.

Recommendation: Add descriptive, context-specific alt tags.
